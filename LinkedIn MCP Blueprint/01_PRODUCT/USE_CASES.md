# Use Cases

1. User connects a LinkedIn account using an approved OAuth flow.
2. User checks connection status and granted scopes.
3. AI discovers available MCP tools and their permission requirements.
4. User retrieves permitted profile, organization, or content data.
5. User performs permitted content actions, only if API access exists and explicit confirmation requirements are met.
6. User views usage/limits and disconnects account.
7. Admin diagnoses service issues without inspecting private member content unnecessarily.

These are goals, not claims that LinkedIn exposes every capability. Phase 0 must map each use case to real API access or mark it unavailable.
