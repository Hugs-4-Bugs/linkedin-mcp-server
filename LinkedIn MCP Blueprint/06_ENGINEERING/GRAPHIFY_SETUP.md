# Graphify / Code Graph Setup

Graphify is a candidate tool, not a mandatory unverified dependency. Agent must verify its official repository/docs, current installation, supported language, security posture, license, output formats and compatibility before installation. If suitable, pin version and run graph generation on source code only; exclude secrets, build artifacts, node_modules and sensitive data. Document reproducible command, output path and update procedure.

If Graphify is unavailable or incompatible, use a documented alternative such as dependency graph tooling, TypeScript compiler analysis, import graph/lint rules or repository-specific graph generation. Do not claim a graph tool is installed until verified.
