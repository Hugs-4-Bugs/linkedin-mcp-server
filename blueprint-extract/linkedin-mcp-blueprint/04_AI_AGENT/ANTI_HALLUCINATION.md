# Anti-Hallucination Protocol

For every LinkedIn capability: official docs URL, endpoint/API product, exact required scope, current access status, partner/application approval requirement, limitations, evidence date and verification method. Unknown = UNKNOWN, not available.

For host/client integration: verify official host docs, transport, auth, deployment requirements, discovery/tool-call limitations and current compatibility. Do not claim connection success until end-to-end test.

For code: report test command and observed result. Use explicit status: VERIFIED, PARTIALLY VERIFIED, UNVERIFIED, BLOCKED.
