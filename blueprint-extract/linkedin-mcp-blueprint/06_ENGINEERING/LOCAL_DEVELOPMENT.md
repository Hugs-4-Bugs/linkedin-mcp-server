# Local Development

1. Install verified runtime and package manager.
2. Clone repository and install lockfile dependencies.
3. Copy `.env.example` to ignored local env file and set local-only values.
4. Run checks and tests.
5. Start stdio MCP mode for supported local client tests.
6. Use test account, authorized scopes and synthetic fixtures where possible.
7. Never use production credentials or sensitive real content in development logs.
