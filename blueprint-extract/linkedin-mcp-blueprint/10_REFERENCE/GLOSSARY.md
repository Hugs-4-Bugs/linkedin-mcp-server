# Glossary

MCP: Model Context Protocol, a standard for AI hosts to connect to tools/context servers. OAuth: authorization protocol used for delegated access. Scope: permission granted to application. Tenant: isolated customer/workspace boundary. Entitlement: feature/plan authorization. Quota: usage limit. Transport: connection mechanism such as stdio or Streamable HTTP. Adapter: isolated integration layer for LinkedIn API. ADR: Architecture Decision Record. Graphify: code/dependency graph analysis tool (verify specific project/tool before use).
