# FAQ

**Can all LinkedIn features be exposed?** No; API availability and permissions are limited.

**Can it be monetized?** Architecture can support it later, but terms, permissions, cost and demand must be validated.

**Can one server support Claude and ChatGPT?** Potentially, but client auth/transport requirements and feature support must be separately verified.

**Why TypeScript?** First-party MCP SDK maturity and lower integration friction for this project. Java is also capable and scalable.
